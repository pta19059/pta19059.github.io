# Azure Labs

This directory contains hands-on Azure learning labs created by Microsoft App Innovation Specialists.

## Available Labs

1. **Lab 1 - Azure Front Door - APIM - App Service**: Learn to integrate Azure Front Door, API Management, and App Service
2. **Lab 2 - Containers in App Service**: Explore containerized applications in Azure App Service  
3. **Lab 3 - Brainstorming App**: Build a business idea generation app using Azure OpenAI

Visit the [Main Page](Main_Page.md) to get started with the labs.
